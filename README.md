# TLBD English — GitHub Pages

## Publicación
1. Usa una cuenta de GitHub con el usuario `tlbdenglish`.
2. Crea un repositorio público llamado `tlbdenglish.github.io`.
3. Sube `index.html` y la carpeta `assets`.
4. Activa GitHub Pages desde Settings > Pages.
5. La dirección esperada es https://tlbdenglish.github.io/

## Multimedia
Las carpetas `assets/images` y `assets/videos` están preparadas para incorporar las fotografías y videos institucionales.

## Formulario
El formulario prepara la solicitud y abre WhatsApp. Para producción, conviene revisar las políticas legales y condiciones de garantía antes de publicar.
